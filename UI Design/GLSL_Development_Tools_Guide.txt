  URL: https://www.shadertoy.com

  Pros:
    ✅ Real-time preview (instant feedback)
    ✅ Huge community library (learn from examples)
    ✅ Built-in uniforms (mouse, time, resolution)
    ✅ No installation required
    ✅ Save and share shaders online
    ✅ Performance metrics displayed
    ✅ Multiple buffer support (for multi-pass rendering)
  
  Cons:
    ⚠️ Fragment shader only (no vertex shader editor)
    ⚠️ Slightly different syntax than standard GLSL
    ⚠️ Requires internet connection
  
  Best For:
    • Testing fog gradients
    • Color mixing algorithms
    • Circular dot rendering
    • Glow effects
    • Background grid patterns
  
  Quick Start:
    1. Go to shadertoy.com
    2. Click "New Shader"
    3. Replace default code with your fragment shader
    4. Press Alt+Enter to compile
    5. See real-time result
  
  Example Usage:
    void mainImage(out vec4 fragColor, in vec2 fragCoord) {
        vec2 uv = fragCoord / iResolution.xy;
        
        // Test red fog gradient
        float fogIntensity = 0.0;
        vec3 fogColor = vec3(0.0);
        if (uv.y > 0.7) {
            fogIntensity = (uv.y - 0.7) / 0.3;
            fogColor = vec3(1.0, 0.0, 0.0);
        }
        
        fragColor = vec4(fogColor, fogIntensity * 0.5);
    }

         if (uv.y > 0.7) {

             color = mix(color, vec3(1.0, 0.0, 0.0), fog * 0.4);
         }
         // Blue fog test
         if (uv.y < 0.3) {
             float fog = (0.3 - uv.y) / 0.3;

         }
         
         fragColor = vec4(color, 1.0);
     }
