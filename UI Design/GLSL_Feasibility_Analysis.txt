================================================================================
                       5. TECHNICAL CHALLENGES & SOLUTIONS
================================================================================

CHALLENGE 1: Mouse Picking (Detecting Which Dot is Hovered)
────────────────────────────────────────────────────────────
  Problem: GLSL doesn't have built-in "which point did user click?"
  
  ✅ Solution 1 (GPU-based): Render-to-texture picking
    - Render dots with unique colors in hidden buffer
    - Read pixel color at mouse position
    - Map color back to sample index
    - Performance: Excellent (GPU does all work)
  
  ✅ Solution 2 (CPU-based): Distance calculation
    - Transform mouse position to 3D space
    - Calculate distance to each dot in HISE Script
    - Find nearest dot within threshold
    - Performance: Good (JavaScript fast enough for 144 samples)
  
  Recommendation: Solution 2 (simpler to implement, sufficient performance)

CHALLENGE 2: 3D Rotation/Navigation
────────────────────────────────────
  Problem: User needs to rotate view to see occluded dots
  
  ✅ Solution: View matrix manipulation
    - Mouse drag → calculate rotation angles
    - Update viewMatrix uniform in real-time
    - Smooth interpolation for "physics" feel
    - Lock to reasonable rotation limits (no upside-down)
  
  Implementation: Standard 3D camera math (well-documented)

CHALLENGE 3: Depth Sorting (Front Dots Over Back Dots)
───────────────────────────────────────────────────────
  Problem: Without proper sorting, back dots might render over front
  
  ✅ Solution: Enable depth testing
    - OpenGL depth buffer (gl.enable(gl.DEPTH_TEST))
    - Dots automatically sorted by GPU
    - No manual sorting needed
  
  One-line fix in HISE Panel setup

CHALLENGE 4: Anti-Aliasing (Smooth Circles, Not Pixelated)
───────────────────────────────────────────────────────────
  Problem: Small dots might look jagged without AA
  
  ✅ Solution: Shader-based MSAA
    - Use smoothstep() in fragment shader
    - Calculate distance from center, smooth edges
    - No performance cost (GPU does automatically)
  
  Already included in mockup shader code

CHALLENGE 5: Performance with 144+ Samples
───────────────────────────────────────────
  Problem: Will 144 dots render smoothly?
  
  ✅ Solution: GPU instancing
    - Modern GPUs handle 10,000+ points easily
    - 144 samples = trivial workload
    - Expected performance: 60fps+ on all systems
  
  Non-issue: GLSL designed for this exact use case

                       8. PROOF OF CONCEPT CODE
================================================================================

MINIMAL VERTEX SHADER (vertex.glsl)
────────────────────────────────────
```glsl
attribute vec3 position;
attribute float size;
attribute vec4 color;
uniform mat4 projection;
uniform mat4 view;
varying vec4 vColor;

void main() {
    vec4 viewPos = view * vec4(position, 1.0);
    gl_Position = projection * viewPos;
    gl_PointSize = size * (1.0 / -viewPos.z);  // perspective scaling
    vColor = color;
}
```

MINIMAL FRAGMENT SHADER (fragment.glsl)
────────────────────────────────────────
```glsl
precision mediump float;
varying vec4 vColor;

void main() {
    vec2 coord = gl_PointCoord - vec2(0.5);
    float dist = length(coord);
    if (dist > 0.5) discard;  // circular shape
    
    float alpha = 1.0 - smoothstep(0.45, 0.5, dist);  // soft edges
    gl_FragColor = vec4(vColor.rgb, vColor.a * alpha);
}
```

HISE SCRIPT INTEGRATION (Interface.js)
───────────────────────────────────────
```javascript
// Create GLSL panel
const ScatterPanel = Content.getComponent("ScatterPanel");

// Load shaders
ScatterPanel.loadShader("vertex.glsl");
ScatterPanel.loadShader("fragment.glsl");

// Sample data (attack, decay, brightness)
const samples = [
    {name: "808 - Tyler", pos: [0.3, 0.5, 0.6], color: [1.0, 0.0, 0.0, 1.0]},
    {name: "808 - MURDA", pos: [0.7, 0.8, 0.5], color: [0.8, 0.0, 0.0, 1.0]},
    // ... 142 more samples
];

// Update shader with sample positions
ScatterPanel.setShaderValue("samplePositions", samples.map(s => s.pos));
ScatterPanel.setShaderValue("sampleColors", samples.map(s => s.color));

// Mouse hover handler
ScatterPanel.setMouseCallback(function(event) {
    if (event.hover) {
        // Calculate nearest sample to mouse position
        const nearest = findNearestSample(event.x, event.y);
        ScatterPanel.setShaderValue("hoveredIndex", nearest);
    }
});
```
