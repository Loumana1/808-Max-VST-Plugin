                        1. 808 CATEGORIZATION SYSTEM
================================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. DURATION / DECAY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Sub Short      - Tight, punchy, quick decay (< 1 second)
  • Sub Medium     - Balanced sustain (1-2 seconds)
  • Sub Long       - Extended sustain, room-filling (2-4 seconds)
  • Infinite       - No decay, sustained note

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
B. TEXTURE / HARMONIC CONTENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Clean          - Pure sine wave, minimal harmonics
  • Rumble         - Mid-bass texture, chest-hitting
  • Reese          - Detuned layers, wobbly modulation
  • Distorted      - Saturated, clipped, aggressive
  • Saturated      - Warm analog coloration
  • Gritty         - Noisy, textured attack
  • Metallic       - Industrial, harmonic-rich (BNYX style)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
C. ATTACK / TRANSIENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Clicky         - Sharp transient attack
  • Soft           - Rounded, smooth onset
  • Punchy         - Mid-range knock
  • With Kick      - Layered kick transient
  • No Kick        - Pure sub bass
  • Snap           - Short, percussive attack

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
D. FREQUENCY RANGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Sub Heavy      - Dominated by 20-60Hz
  • Mid-Present    - Audible on small speakers (80-200Hz)
  • Hi-End         - Top harmonics for definition
  • Dark           - Low-pass filtered, muffled
  • Bright         - Extended high-frequency content
  • Balanced       - Even frequency distribution

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
E. PITCH BEHAVIOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Static         - Single pitch, no modulation
  • Glide          - Portamento/slide between notes
  • Pitch Drop     - Downward pitch envelope
  • Pitch Rise     - Upward sweep
  • Wobble         - LFO modulation (Reese-like)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
F. PRODUCER / ERA STYLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Zay 808        - Zaytoven: melodic, tuned, piano-friendly
  • CTM 808        - CashMoneyAP/modern trap: clean, surgical
  • Murda 808      - Murda Beatz: layered kick + sub
  • Lex Luger      - Hard-hitting, sliding, aggressive
  • Mike Will      - Modulated, textured, atmospheric
  • 808 Mafia      - TM88/Southside: boomy, sustained
  • Pi'erre        - Melodic glides, rhythmic slides
  • Spinz          - Modern: tight, punchy
  • Memphis        - Three 6 Mafia: lo-fi, cassette warmth
  • Miami Bass     - 2 Live Crew: boomy, club-oriented
  • Drill          - UK/NY drill: detuned, ominous

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
G. MOOD / VIBE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Aggressive     - In-your-face, distorted
  • Dark           - Ominous, minor-key friendly
  • Warm           - Analog, vintage saturation
  • Cold           - Digital, surgical, clean
  • Bouncy         - Rhythmic, danceable
  • Heavy          - Weight, physical presence
  • Airy           - Spacious, reverb-tailed

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
H. GENRE / USE CASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Lo-Fi          - Vintage, warm, filtered
  • EDM            - Festival-ready, sidechain-friendly

                    2. UI FILTERING SYSTEM STRUCTURE
================================================================================

PRIMARY FILTERS (Main Navigation)
──────────────────────────────────
  1. ATTACK     → Clicky | Soft | Punchy | With Kick | No Kick
  2. DECAY      → Short | Medium | Long | Infinite
  3. TEXTURE    → Clean | Rumble | Reese | Distorted | Gritty | Metallic
  4. STYLE      → Zay | CTM | Murda | Lex | Pi'erre | Memphis | Drill
  5. FREQ       → Sub Heavy | Balanced | Bright | Dark

───────────────────────────────
  • Pitch Behavior: Static | Glide | Drop | Rise | Wobble
  • Vibe: Aggressive | Dark | Warm | Bouncy | Heavy
  • Genre: Trap | Drill | R&B | Lo-Fi | EDM | Afrobeats

================================================================================
                      3. VISUAL DESIGN SPECIFICATIONS
================================================================================

COLOR PALETTE
─────────────
  Background:     #0A0A0A (Near-black)
  Panel BG:       #1A1A1A (Dark gray)
  Primary Red:    #8B0000 (Dark blood red)
  Accent Red:     #FF0000 (Bright red for selections)
  Hover Red:      #B30000 (Medium red)
  Text Primary:   #E0E0E0 (Light gray)
  Text Secondary: #808080 (Medium gray)
  Dividers:       #2A2A2A (Subtle dark gray)

TYPOGRAPHY
──────────
  Headers:        18-24px, Bold, Sans-serif (e.g., Roboto Bold)
  Body:           12-14px, Regular, Sans-serif
  Sample Names:   14px, Medium, Monospace (e.g., SF Mono)
  Tags:           10-11px, Regular, Sans-serif

3D SCATTER PLOT SPECIFICATIONS
───────────────────────────────
  Axes:
    X-Axis: Attack (Soft ←→ Clicky)
    Y-Axis: Decay (Short ←→ Long)
    Z-Axis: Brightness (Depth via color/size)
  
  Dot Representation:
    • Size: 6-16px (based on popularity/rating)
    • Color: Red gradient (Dark Red → Bright Red based on brightness)
    • Hover: Scale 1.3x + glow effect
    • Selected: Bright red (#FF0000) + outer ring
    • Alpha: 0.7-1.0 (depth illusion)
  
  Grid:
    • Subtle dark red lines (#2A0000)
    • Perspective distortion for 3D effect
    • Fading opacity towards back

INTERACTION STATES
──────────────────
  Default:     Red dots (#8B0000), 70% opacity
  Hover:       Bright red (#FF0000), 100% opacity, scale 1.3x
  Selected:    Bright red (#FF0000), outer glow, pulsing animation
  Filtered:    Full opacity, other dots dimmed to 30%

================================================================================
                      5. INTERACTION & ANIMATION
================================================================================

SCATTER PLOT INTERACTIONS
─────────────────────────
  1. Click Dot       → Select sample, update details panel
  2. Hover Dot       → Show tooltip with sample name
  3. Drag Background → Rotate 3D view (subtle parallax)
  4. Scroll          → Zoom in/out
  5. Double-Click    → Reset view to default

FILTER INTERACTIONS
───────────────────
  1. Click Filter    → Toggle on/off, update visible dots
  2. Multi-Select    → AND logic (all filters must match)
  3. Clear All       → Button to reset filters
  4. Filter Count    → Show "X samples match"

ANIMATIONS
──────────
  • Dot Selection:    0.2s ease-out scale + glow
  • Filter Toggle:    0.15s ease background color
  • View Rotation:    Smooth 60fps animation
  • Dot Filtering:    0.3s fade in/out
  • Hover:            0.1s scale transform

KEYBOARD SHORTCUTS
──────────────────
  • Arrow Keys:       Navigate between dots
  • Enter:            Select highlighted dot
  • Space:            Play/preview sample
  • ESC:              Clear filters
  • R:                Random sample
  • F:                Focus search/filter

================================================================================
                      6. TECHNICAL IMPLEMENTATION
================================================================================

HISE + GLSL RENDERING
─────────────────────
  • ScriptPanel for main viewport
  • GLSL Fragment Shader for 3D scatter plot
  • ScriptButton array for filters
  • ScriptLabel for details panel
  • Custom Paint Routines for non-GLSL elements

DATA STRUCTURE
──────────────
  Each sample stored with:
    {
      name: "808 - Tyler",
      attack: 0.3,      // 0.0 (soft) to 1.0 (clicky)
      decay: 0.5,       // 0.0 (short) to 1.0 (long)
      brightness: 0.6,  // 0.0 (dark) to 1.0 (bright)
      tags: ["Warm", "Bouncy", "Memphis", "Sub Heavy"],
      style: "Memphis",
      genre: "Trap"
    }

GLSL SHADER RESPONSIBILITIES
────────────────────────────
  • Render 3D-perspective grid
  • Draw sample dots with depth
  • Apply color gradients
  • Glow effects on hover/selection
  • Real-time filtering visual updates
  • Smooth transitions

HISE SCRIPT RESPONSIBILITIES
────────────────────────────
  • Sample loading and management
  • Filter logic and state
  • Mouse/keyboard input handling
  • Sample selection callback
  • UI state management
