================================================================================
                        1. AXIS MAPPING & LAYOUT
================================================================================

X-AXIS: DECAY (LEFT → RIGHT)
────────────────────────────
  LEFT (0.0):     Short decay (< 1 sec) - Tight, punchy
  CENTER (0.5):   Medium decay (1-2 sec) - Balanced
  RIGHT (1.0):    Long decay (2-4+ sec) - Boomy, sustained
  
  Label: "SHORT ←─────── DECAY ───────→ LONG"

Y-AXIS: CLEANNESS vs DISTORTION (BOTTOM → TOP) ⚠️ KEY CHANGE
────────────────────────────────────────────────────────────
  BOTTOM (0.0):   Clean - Pure sine wave, minimal harmonics
  CENTER (0.5):   Warm - Light saturation, analog character
  TOP (1.0):      Distorted - Heavy saturation, aggressive

  Label: "CLEAN ↑──── CLEANNESS vs DISTORTION ────↑ DISTORTED"
  
  ⚠️ CRITICAL: Natural visual metaphor:
     • Clean samples "sink" to bottom (blue fog)
     • Distorted samples "rise" to top (red fog)

Z-AXIS: BRIGHTNESS (DEPTH via COLOR & SIZE)
────────────────────────────────────────────
  DARK (0.0):     Sub-heavy, no high-end (smaller, darker)
  MID (0.5):      Balanced frequency response
  BRIGHT (1.0):   High-end present (larger, brighter)
  
  Representation: Dot size + Color intensity

  Opacity: 0.0 (at Y=0.7) → 0.5 (at Y=1.0)

    ║ ████████████████████████████████    ║  ← Y = 0.7
    ║                                     ║
    ║         CLEAR ZONE                  ║  ← Y = 0.3 to 0.7
    ║                                     ║
    ║ ████████████████████████████████    ║  ← Y = 0.3

BLUE FOG (BOTTOM REGION - Clean Zone) 🔵
────────────────────────────────────────
  Position: Y = 0.0 to 0.3 (bottom 30% of viewport)
  Color: #0066FF → #003380 (ice blue to dark blue)
  Opacity: 0.5 (at Y=0.0) → 0.0 (at Y=0.3)
  Effect: Cool, clean atmosphere suggests purity

CLEAR ZONE (MIDDLE REGION)
───────────────────────────
  Position: Y = 0.3 to 0.7 (middle 40% of viewport)
  Color: Pure black (#0A0A0A)
  Opacity: 0.0 (no fog)
  Effect: Neutral visibility zone

FOG SHADER CODE
───────────────
```glsl
float fogIntensity = 0.0;
vec3 fogColor = vec3(0.0);

// Red fog (top - distorted zone)
if (uv.y > 0.7) {
    fogIntensity = pow((uv.y - 0.7) / 0.3, 2.0);  // Non-linear
    fogColor = mix(vec3(0.54, 0.0, 0.0), vec3(1.0, 0.0, 0.0), fogIntensity);
}
// Blue fog (bottom - clean zone)
else if (uv.y < 0.3) {
    fogIntensity = pow((0.3 - uv.y) / 0.3, 2.0);
    fogColor = mix(vec3(0.0, 0.2, 0.4), vec3(0.0, 0.4, 1.0), fogIntensity);
}

// Blend fog with scene
vec3 finalColor = mix(sceneColor.rgb, fogColor, fogIntensity * 0.4);
```

              3. MULTI-LAYERED VISUAL ENCODING SYSTEM
================================================================================

ATTACK → ENCODED IN BORDER THICKNESS
─────────────────────────────────────
  Soft Attack:      ● Smooth circle, no border (0.0)
  Medium Attack:    ◐ Circle with thin border (0.3-0.5)
  Punchy Attack:    ⊙ Circle with thick border (0.6-0.8)
  Clicky Attack:    ◉ Circle with double ring (0.9-1.0)
  With Kick:        ⦿ Circle with outer halo
  
  Implementation:
    • Border thickness: 0px (soft) to 4px (clicky)
    • Border color: Slightly brighter than dot color
  
  Shader Code:
  ```glsl
  float borderSize = vAttack * 0.15;  // 0.0 to 0.15
  float borderStart = 0.35;
  float borderEnd = 0.5;
  
  if (dist > borderStart && dist < borderEnd) {
      float borderAlpha = smoothstep(borderStart, borderStart + 0.05, dist) *
                         (1.0 - smoothstep(borderEnd - 0.05, borderEnd, dist));
      color.rgb = mix(color.rgb, vec3(1.0), 0.5);  // Brighter border
      alpha = max(alpha, borderAlpha);
  }
  ```

TONE/STYLE → ENCODED IN COLOR HUE
──────────────────────────────────
  Pure Sub Bass:    ● Deep Red (#8B0000)
  808 Classic:      ● Blood Red (#FF0000)
  Reese:            ● Red-Orange (#FF3300)
  Bass Guitar:      ● Orange-Red (#FF6600)
  Brassy:           ● Orange (#FF9900)
  Synth:            ● Red-Purple (#CC0066)
  
  Implementation:
    • Base color determined by tone category
    • Brightness still controls intensity (Z-axis)
    • Details panel shows full tone description
  
  Shader Code:
  ```glsl
  vec3 toneColors[6] = vec3[](
      vec3(0.54, 0.0, 0.0),   // Pure Sub (dark red)
      vec3(1.0, 0.0, 0.0),    // 808 Classic (blood red)
      vec3(1.0, 0.2, 0.0),    // Reese (red-orange)
      vec3(1.0, 0.4, 0.0),    // Bass Guitar (orange-red)
      vec3(1.0, 0.6, 0.0),    // Brassy (orange)
      vec3(0.8, 0.0, 0.4)     // Synth (red-purple)
  );
  vec3 baseColor = toneColors[int(tone)];
  vColor = vec4(baseColor * (0.5 + position.z * 0.5), 0.7);
  ```

ENCODING LAYERS SUMMARY
───────────────────────
  1. POSITION (X, Y)     → Decay + Cleanness/Distortion
  2. FOG ENVIRONMENT     → Reinforces distortion level
  3. COLOR HUE           → Tone/Style (Pure Sub → Brassy)
  4. SIZE                → Brightness (Z-axis depth)
  5. BORDER THICKNESS    → Attack characteristics
  6. HOVER/SELECTION     → Interactive state (glow, scale)

                       8. GLSL SHADER SPECIFICATIONS
================================================================================

VERTEX SHADER (scatter_vertex.glsl)
────────────────────────────────────
```glsl
attribute vec3 position;      // x=decay, y=cleanness, z=brightness
attribute float attack;       // 0.0 to 1.0
attribute float tone;         // 0-5 (category index)
attribute float sampleIndex;  // Unique ID for hover/selection

uniform mat4 projection;
uniform mat4 view;
uniform vec2 mouse;
uniform int selectedIndex;
uniform int hoveredIndex;
uniform float time;

varying vec4 vColor;
varying float vSize;
varying float vAttack;
varying float vTone;
varying float vSampleIndex;

void main() {
    // Transform position
    vec4 worldPos = vec4(position, 1.0);
    vec4 viewPos = view * worldPos;
    gl_Position = projection * viewPos;
    
    // Calculate size (brightness affects size)
    float baseSize = 10.0 + (position.z * 6.0);  // 10-16px
    float depth = -viewPos.z;
    vSize = baseSize / depth;  // Perspective scaling
    gl_PointSize = vSize;
    
    // Determine color based on tone
    vec3 toneColors[6] = vec3[](
        vec3(0.54, 0.0, 0.0),   // 0: Pure Sub (dark red)
        vec3(1.0, 0.0, 0.0),    // 1: 808 Classic (blood red)
        vec3(1.0, 0.2, 0.0),    // 2: Reese (red-orange)
        vec3(1.0, 0.4, 0.0),    // 3: Bass Guitar (orange-red)
        vec3(1.0, 0.6, 0.0),    // 4: Brassy (orange)
        vec3(0.8, 0.0, 0.4)     // 5: Synth (red-purple)
    );
    vec3 baseColor = toneColors[int(tone)];
    
    // Brightness modulates intensity
    float brightness = 0.5 + position.z * 0.5;
    vColor = vec4(baseColor * brightness, 0.7);
    
    // Pass attributes to fragment shader
    vAttack = attack;
    vTone = tone;
    vSampleIndex = sampleIndex;
}
```

FRAGMENT SHADER (scatter_fragment.glsl)
────────────────────────────────────────
```glsl
precision mediump float;

varying vec4 vColor;
varying float vSize;
varying float vAttack;
varying float vTone;
varying float vSampleIndex;

uniform int hoveredIndex;
uniform int selectedIndex;
uniform float time;

void main() {
    vec2 coord = gl_PointCoord - vec2(0.5);
    float dist = length(coord);
    
    // Discard outside circle
    if (dist > 0.5) discard;
    
    // Base circle with anti-aliasing
    float alpha = 1.0 - smoothstep(0.45, 0.5, dist);
    vec4 color = vColor;
    
    // Add border based on attack
    float borderSize = vAttack * 0.15;  // 0.0 to 0.15
    float borderStart = 0.35 - borderSize;
    float borderEnd = 0.5;
    
    if (dist > borderStart && dist < borderEnd && vAttack > 0.2) {
        float borderAlpha = smoothstep(borderStart, borderStart + 0.05, dist) *
                           (1.0 - smoothstep(borderEnd - 0.05, borderEnd, dist));
        color.rgb = mix(color.rgb, vec3(1.0), 0.5);  // Brighter border
        alpha = max(alpha, borderAlpha);
    }
    
    // Hover effect
    if (int(vSampleIndex) == hoveredIndex) {
        float glow = (1.0 - dist * 2.0) * 0.3;
        color.rgb += vec3(glow);
        alpha = 1.0;
    }
    
    // Selection effect with pulsing
    if (int(vSampleIndex) == selectedIndex) {
        float pulse = 0.9 + 0.1 * sin(time * 3.14159);  // Pulsing 0.9-1.0
        float glow = (1.0 - dist * 2.0) * 0.5 * pulse;
        color.rgb += vec3(glow);
        alpha = 1.0;
    }
    
    gl_FragColor = vec4(color.rgb, color.a * alpha);
}
```

FOG OVERLAY SHADER (fog_overlay.glsl)
──────────────────────────────────────
```glsl
precision mediump float;

uniform vec2 resolution;
uniform sampler2D sceneTexture;

void main() {
    vec2 uv = gl_FragCoord.xy / resolution;
    vec4 sceneColor = texture2D(sceneTexture, uv);
    
    // Calculate fog
    float fogIntensity = 0.0;
    vec3 fogColor = vec3(0.0);
    
    // Red fog (top - distorted zone)
    if (uv.y > 0.7) {
        fogIntensity = pow((uv.y - 0.7) / 0.3, 2.0);  // Non-linear falloff
        fogColor = mix(vec3(0.54, 0.0, 0.0), vec3(1.0, 0.0, 0.0), fogIntensity);
    }
    // Blue fog (bottom - clean zone)
    else if (uv.y < 0.3) {
        fogIntensity = pow((0.3 - uv.y) / 0.3, 2.0);  // Non-linear falloff
        fogColor = mix(vec3(0.0, 0.2, 0.4), vec3(0.0, 0.4, 1.0), fogIntensity);
    }
    
    // Blend fog with scene
    vec3 finalColor = mix(sceneColor.rgb, fogColor, fogIntensity * 0.4);
    gl_FragColor = vec4(finalColor, 1.0);
}
```

GRID BACKGROUND SHADER (grid.glsl)
───────────────────────────────────
```glsl
precision mediump float;

uniform vec2 resolution;
uniform mat4 viewMatrix;

void main() {
    vec2 uv = gl_FragCoord.xy / resolution;
    
    // Create 3D grid with perspective
    float gridSize = 0.05;
    float lineWidth = 0.002;
    
    vec2 grid = abs(fract(uv / gridSize - 0.5) - 0.5) / fwidth(uv / gridSize);
    float line = min(grid.x, grid.y);
    
    // Dark gray grid color
    vec3 gridColor = vec3(0.1, 0.1, 0.1);  // #1A1A1A
    float gridAlpha = 1.0 - min(line, 1.0);
    
    // Fade towards back (depth illusion)
    float depth = uv.y;
    gridAlpha *= (1.0 - depth * 0.5);
    
    gl_FragColor = vec4(gridColor, gridAlpha * 0.3);
}
```
